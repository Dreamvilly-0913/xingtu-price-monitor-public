## 本次做了什么

1. **可靠采价**：促销优惠、运费、库存、无报价和多金额歧义不再误判为售价；支持安全提取模板。真实请求有超时、DNS固定连接、逐次跳转校验及1MB响应上限。每次保存脱敏地址、HTTP状态、响应结构摘要、哈希与耗时，失败保留原因。
2. **价格与预警对账**：成功价附实际采集时间、年龄、配置身份及陈旧状态；陈旧、停用或失配的报价不参与当前最低价。24小时跌幅只采用相近时间、同来源、同配置的真实历史基线，保存该基线便于复核；修改规则立即重评且不造价格点，定时清理失效提醒。
3. **账号与运维**：生产空库用随机初始化凭证创建强密码管理员；默认口令受限，改密撤销旧JWT，登录限流。拒绝生产占位密钥，增加操作审计、真实采集配置预览和准备状态提示。提供SQLite在线一致快照、恢复核验及Docker持久化备份卷。
4. **运营体验与容量**：可见页面每30秒刷新，操作后更新未读数；分类独立查询、分组远程搜索，不截断在100条。列表数据库分页、仪表盘按选择加载至多10条曲线，长历史保首尾/极值采样，统计仍使用全部流水。调度限制并发、同站点串行和间隔，停机等待落库。

价格仍只由采集器产生，商品表未增加现价或统计缓存。演示源、真实源及混合历史均保留准确来源标签。未自动接入或伪造任何平台报价。

## 遗留问题与使用边界

- 京东公开接口外部探针仍未获得HTTP响应；天猫、拼多多线上接口尚未接通。实际运营需配置有权使用、可访问且语义明确的价格接口/网页或内部价格网关，先试采并对账，再启用。设置页在没有有效真实报价时提示阻塞原因。
- 单一团队管理员、单个后端实例及进程内node-cron；尚无多角色、消息渠道推送、分布式调度或限流共享存储。它适合单团队试运营，不宣称具备多租户或高可用能力。
- 网页可能动态渲染、要求登录或拦截；本系统只解析fetch拿到的响应，不自动登录或计算未返回的券后价。失败不补模拟价格。
- SQLite升级使用先备份再非破坏性schema同步；大规模PostgreSQL上线应建立受控版本迁移，在目标环境验证备份、运行和恢复。
- 真正上线还需在目标主机配置HTTPS、常驻进程、授权数据源和外部备份保留策略；本次没有部署到公开服务器。
